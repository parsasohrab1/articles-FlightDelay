# Business Requirements Specification – FlightDelay

| ID | Requirement |
|----|-------------|
| BR-1 | Give a planner an arrival-delay interval for a flight before it departs, using only information known at that time. |
| BR-2 | Report the real coverage of the interval overall and for late-day flights and flights whose aircraft arrived late. |
| BR-3 | Quantify what the aircraft's previous-leg delay adds. |
| BR-4 | Report how the January-calibrated interval behaves in July and how much recalibration on a few thousand flights helps. |

Out of scope: weather and air-traffic-control data, departure-delay information, crew and passenger connections, operational deployment.
